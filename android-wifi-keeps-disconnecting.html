Android WiFi Keeps Disconnecting – How to Fix

If your Android phone frequently disconnects from WiFi, it can be caused by battery optimization or network settings.

Fix 1: Disable Battery Optimization for WiFi

Battery saver modes often limit WiFi performance.

Fix 2: Forget and Reconnect WiFi Network

  1. Settings → WiFi
  2. Forget network
  3. Reconnect with password

Fix 3: Reset Network Settings

This clears corrupted network configurations.
